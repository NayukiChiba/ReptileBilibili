## 介绍

该项目是一个**[bilibili](https://www.bilibili.com/)用户信息爬取程序**，它可以抓取用户的关注列表，收藏夹，历史视频，up主视频等信息。难度个人觉得

还是比较大的，所以进行了比较长时间的学习，而且作为一个爬虫项目，如果真的想用，请谨慎使用，不要对网站进行过多的请求~~(容易被封号)~~

## 必备知识

* 设计语言：python, csv
* 第三方库：**selenium**, request, re, csv, time等
* 数据清洗：csv, re
* 数据储存：csv

## 功能

* 用户关注的所有up主，保存到csv文件
* up主最近更新的10个视频
* up主最热门的10个视频
* 默认收藏夹的所有视频
* 七天前的看过的视频
* 视频的tag读取

## 程序启动

1. 你可以根据自己的需要，去启动不同的文件
2. 你可以直接启动main.py文件，运行所有的程序

## 注意

* 再次强调！不要进行过多请求
* 如果程序的cookie报错，可以选择直接进入config.py文件中加入语句:

​	cookie = ‘**cookie**’      将**cookie**改成自己的cookie即可

* 程序运行过程很长，特别是up主视频信息爬取，毕竟是10*10 * 算量，而且要去每一个网站，并且定位，所以请耐心等待，没有报错，他就是在运行，浏览器会一直占屏幕的左侧.
